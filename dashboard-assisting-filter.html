Show Only Assisting — notes

  • New toggle sits under Show Inactive Vehicles; same toggle component (off #CBD5E1, on #20315A).
  • Toggle on → list and map show only vehicles currently in route-assist mode.
  • Assisting cards always show an Assisting tag and a chevron at the bottom-right, aligned with the vehicle type line.
  • Chevron opens/closes the assisted-vehicle block: vehicle name, driver, vehicle type of the vehicle being assisted.
  • Toggle off → assisting cards start closed. Toggle on → all cards start open; user can close any.
  • Map clusters reflect the filtered set.

  • dashboard-vehicle-card-assisting
  • dashboard-assisted-vehicle-details
