Vehicles page filters: how it works

Behavior of every new or moved control in SCP-5321. Anything not listed here works exactly as it does today.

Vehicle Subtype filter

  • Shows only on portals with vehicle subtypes on. With subtypes off, the top row has no subtype filter.
  • Lists the vendor's subtypes. Add-ons are not listed.
  • With no vehicle type selected, each subtype shows its vehicle type next to it, for example "Hook Lift (Roll Off)".
  • With a vehicle type selected, it lists only that type's subtypes.
  • If the user changes the vehicle type and the selected subtype doesn't belong to the new type, the subtype filter clears.
  • Selecting a subtype shows only the vehicles with that subtype. The summary cards count only those vehicles.

More filters and the second row

  • Clicking More filters opens a second row under the top row, with Vehicle Status, Service Status and Operational Facility. Clicking it again closes the row.
  • The second row uses the same dropdowns as the top row and filters exactly as those filters do today.
  • When the row is closed and any of its filters is applied, the button shows how many, for example "More filters 2". The count hides while the row is open, because the filters are visible.
  • When the page loads with a second-row filter already applied (from a shared link or the browser's back button), the row opens on its own, so an applied filter is never hidden.

Clearing filters

  • Each applied dropdown shows a small × that clears just that filter.
  • Clear all filters appears once any filter or the search is applied. It resets every filter on both rows and the search, and the list returns to all vehicles.
  • With nothing applied, the link doesn't show.

Export and summary charts

  • The Vehicles export and the summary charts apply the subtype filter, the same as they apply Vehicle Type today.
  • This needs a backend change: the vehicle list, summary and export need to accept the subtype filter. A sibling backend ticket covers it. Until it ships, the export and charts ignore the subtype.
