Snow/Sweeper Route Reset

Applies only to Snow Plow and Street Sweeper routes for this vendor

Sets the Route % Complete threshold that decides what happens when a driver logs into a snow or sweeper route that already has one or more drivers on it. At or above this percent complete, the new driver starts a new route instance as the primary/additional driver. Below it, the new driver is automatically logged in as an assisting driver on the existing route — no prompt is shown to the driver either way. This value is global for this vendor; there is no per-route override.

⚠️ Not yet configured. Until a value is saved, the automatic login-routing behavior is undefined — see the open engineering question on SCP-5078.
