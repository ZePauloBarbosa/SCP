Break Types

Options drivers see when they switch into Not Servicing mode. Each route type keeps its own list — up to 5 break types, 20 characters per label. Default break types can be made active/inactive but not edited or deleted; custom break types can be edited, toggled, or permanently deleted. The Break Time switch below turns break tracking on or off for that route type entirely — turning it off disables every break type in the list until it's back on.
